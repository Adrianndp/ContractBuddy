# ContractBuddy

A small local RAG app for asking questions about my own contracts (rental, phone, insurance, employment, …), mostly in German.
Upload contract PDFs, ask questions, get answers that quote the relevant clause and cite document + page.

**Everything runs locally on purpose**: contracts contain personal data. No cloud APIs, hosted LLMs, telemetry or other
external calls that would send document text or questions off the machine (details in `backend/CLAUDE.md`).

## Structure
```
ContractBuddy/
├── CLAUDE.md                    # this file: overall structure, how the parts connect, how to run
├── backend/                     # FastAPI + Postgres/pgvector + Ollama. Details, conventions, API contract: backend/CLAUDE.md
└── frontend/                    # React UI: TanStack Start in SPA mode, TypeScript, Tailwind v4, shadcn/ui
    ├── AGENTS.md                # frontend architecture rules
    ├── package.json             # npm (needs npm >= 11), lockfile: package-lock.json
    ├── vite.config.ts           # plain Vite config, dev server on :8080, SPA build
    ├── vitest.config.ts
    ├── eslint.config.js         # ESLint + Prettier (.prettierrc: printWidth 100)
    ├── components.json          # shadcn CLI config (for `npx shadcn add <component>`)
    ├── .env.example             # VITE_API_URL
    ├── public/                  # favicon.ico, robots.txt
    └── src/
        ├── styles.css           # Tailwind entry + design tokens; fonts self-hosted via @fontsource
        ├── router.tsx
        ├── routeTree.gen.ts     # generated by TanStack Router, don't edit
        ├── routes/
        │   ├── __root.tsx       # HTML shell, head/meta, 404 + error page
        │   └── index.tsx        # "/" → ContractWorkspace
        ├── components/
        │   ├── contract-workspace.tsx  # the whole app UI: upload, contract list, chat, sources, chunk drawer, health
        │   └── ui/              # shadcn components actually used: alert-dialog, button, checkbox, sheet
        ├── lib/
        │   ├── api.ts           # ALL backend calls and request/response types live here
        │   ├── api.test.ts
        │   └── utils.ts         # cn() class helper
        └── test/                # vitest setup + routing test
```
Both folders may be worked on. The frontend was generated with Lovable but is now maintained here, not in Lovable
(no Lovable packages or config left). Add shadcn components only when they're used (`npx shadcn add <name>`).

## How they connect
```
Browser ──(frontend UI, :8080)
   │  fetch() directly from the browser (no proxy, no server-side fetching)
   ▼
backend FastAPI :8000 ──► Postgres + pgvector (Docker, host port 5433)
                     └──► Ollama on the host :11434 (embeddings + chat)
```
- The frontend is a **static SPA**: `npm run build` writes plain files to `frontend/dist/client` (entry `_shell.html`), no Node server at runtime.
- The frontend's backend URL comes from `VITE_API_URL` (default `http://localhost:8000`). Vite bakes it in at **build time**.
- The backend only accepts browser requests from the origins in `CORS_ORIGINS` (backend `.env`), so the frontend's origin must be listed there.
- The **API contract** is in `backend/CLAUDE.md` and is the source of truth. `frontend/src/lib/api.ts` must match it. Change backend, contract and `api.ts` together.

## How to run (local development)
**Backend**: see "How to run" in `backend/CLAUDE.md` (Postgres via `docker compose`, Ollama on the host, `uvicorn` on :8000).

**Frontend** (from `frontend/`), needs **npm >= 11** (npm 9/10 crash on this dependency tree; with an older npm use `npx npm@11 install`):
```bash
npm install
npm run dev      # → http://localhost:8080 (backend must be running on :8000)
npm run build    # → dist/client
npm run lint
npm test
```
