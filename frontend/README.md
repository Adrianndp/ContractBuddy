# ContractBuddy – Frontend

React UI for ContractBuddy (TanStack Start in SPA mode, TypeScript, Tailwind, shadcn/ui).
Originally generated with Lovable, now maintained in this repo.

Structure, how frontend and backend connect, and how to run everything: see `../CLAUDE.md`.

```sh
npm install      # needs npm >= 11 (npm 9/10 crash on this dependency tree)
npm run dev      # http://localhost:8080
npm run build    # static files in dist/client
npm run lint
npm test
```
